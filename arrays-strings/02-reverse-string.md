## Problem: Reverse String

**LeetCode:** https://leetcode.com/problems/reverse-string/

### Approach

I used the two-pointer approach. One pointer starts from the beginning of the character array and the other starts from the end. I swap the characters and move both pointers toward the center until the string is reversed.

### Complexity

- Time: O(n)
- Space: O(1)
